# Backend Engineering Lab

Laboratório de prática independente de Java, Spring Boot, testes e arquitetura.

## Objetivo

Evoluir a implementação e a capacidade de justificar decisões técnicas por meio de desafios incrementais. O projeto da AlgaWorks (AlgaShop) é referência de consulta, não código a ser copiado.

## Desafio atual

**LAB-001 — Testes REST com REST Assured**

A aplicação-base oferece uma pequena API de produtos pronta para execução. Os testes de integração serão escritos pelo estudante, sem soluções prontas.

Veja [`challenges/001-rest-assured/README.md`](challenges/001-rest-assured/README.md).

## Método

- Base funcional fornecida pelo revisor.
- Tarefas explícitas e critérios de aceite.
- Consulta permitida a documentação e ao AlgaShop; registrar as consultas importantes.
- Revisão do pull request com análise de comportamento, qualidade e decisões.
- Evolução para WireMock e contratos somente após a consolidação dos assuntos.

## Ritmo

4–5 horas semanais de estudo, incluindo AlgaWorks, System Design e o laboratório. O laboratório dispõe inicialmente de até 90 minutos por semana.
